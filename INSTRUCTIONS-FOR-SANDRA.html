Super Easy Start Guide (Coffee Required)

⚠️ FIRST TIME ONLY: The first startup takes 2-3 minutes to install everything. After that, it's 10 seconds!
1
Find the Starter File
Look for one of these files in this folder:

🪟 Windows: Double-click START-PLATFORM.bat
🍎 Mac/Linux: Double-click start-platform.sh

(They have the same coffee cup icon ☕ as this page!)
2
Wait for the Magic
A black window will pop up and start installing things.

📦 First time? Go get coffee, comes back in 2-3 minutes
⚡ After first time? It's ready in 10 seconds!

DO NOT CLOSE THE BLACK WINDOW! Keep it open.
3
Open Your Browser
When you see "PLATFORM IS READY!" in the black window:

1. Open Chrome, Firefox, Safari, or Edge
2. Type this in the address bar: http://localhost:3000
3. Press Enter

🎉 BOOM! Your safety platform is now running!
✅ You're Done!

You should see a beautiful blue page with a rotating safety shield and all your companies.

Click around! Check the Dashboard, Team page, Safety Resources - it's all there!
4
When You're Done
To stop the platform:

1. Close your web browser
2. Go to the black window
3. Press Ctrl+C (or just close the window)

That's it! Everything stops safely.
💡 Pro Tips:

• Bookmark http://localhost:3000 in your browser
• Always start from the starter file (don't try to open it directly in browser)
• If something breaks, just close everything and start over
• Look for the coffee cup button in the header - it's got attitude! 😏
🆘 Having Issues?

1. Make sure Node.js is installed (your tech person should have done this)
2. Try running the starter file again
3. Text your tech-savvy kid/grandkid for help 😄
