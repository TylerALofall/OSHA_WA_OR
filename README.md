## 🆘 Troubleshooting

**Platform won't start?**
1. Make sure Node.js is installed (tech person should have done this)
2. Try running the starter script again
3. Text your kid/grandkid for help 😄

**Black window closed itself?**
- That's okay! Just run the starter script again

**Browser says "can't connect"?**
- Wait a bit longer - first time takes 2-3 minutes
- Make sure the black window is still open
- Check if it says "PLATFORM IS READY!" in the window

**Something broke?**
- Close everything
- Run the starter script again
- 99% of problems are fixed by turning it off and on again! 😄
